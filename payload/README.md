# payload/ — flight board folder

Same role as `fc/` in flightComputer-2027. This is the only folder that depends on the MCU.

| Path | Contents | Exists yet? |
|---|---|---|
| `payload.ioc` | CubeMX configuration | No, needs the MCU |
| `Inc/`, `Src/` | HAL code generated by `stm32pio generate`. Edit only inside `USER CODE` blocks | No |
| `lib/` | Frozen middleware copies (FatFs, FreeRTOS if used) | No |
| `force_fpu.py`, `install_hal_conf.py` | Pre-build scripts copied from FC, adjusted for the chosen MCU family | No |
| `MRT/` | Board glue: `MRT_setup.c` binds HAL handles to modules, `MRT_main.c` runs the application | Stubs |

When the MCU is chosen, follow the "Adding the flight board" steps in [docs/setup.md](../docs/setup.md).
